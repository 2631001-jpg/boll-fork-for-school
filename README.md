# 볼 — 다중 사용자 커뮤니티

다크 모드 한국어 커뮤니티. 프론트엔드는 단일 `index.html`이며 Supabase를 백엔드로 사용함.

## 기능
- 이메일 회원가입/로그인, 프로필 닉네임
- 게시글 작성/수정/삭제, 게시판 분류, 검색
- 댓글 및 대댓글, 추천, 인기순 정렬
- 이미지 첨부 (5MB 제한)
- 신고 접수 및 관리자 권한용 데이터 정책
- 채팅방 기능

## 개발 착수 중인 기능
- 채팅 목록 삭제 기능
  - 실패. supabase sql 수정 필요.
